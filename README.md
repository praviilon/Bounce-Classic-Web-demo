# Bounce Classic Web Demo

Демонстрационная версия браузерной игры в стиле классической **Bounce**
с телефонов Nokia.

- [Ссылка на Демо](https://praviilon.github.io/Bounce-Classic-Web-demo/)

## Описание

Демо содержит один полный уровень, последовательно демонстрирующий
все механики из ТЗ: обычные/движущиеся (горизонтальные и вертикальные)/
ломающиеся платформы, лёд, грязь, шипы, катящийся камень, маятники,
три типа батутов (обычный/сильный/супер), насосы надувания и сдувания,
узкий тоннель (проходим только сдутым шариком), воду с течением (надутый
шарик плавает, обычный медленно тонет, сдутый тонет мгновенно),
вентилятор (поднимает надутый шарик над пропастью), 10 колец, три
контрольные точки, финиш со статистикой и оценкой (S/A/B/C), систему
жизней, паузу, главное меню и настройки громкости.

## Технологии

Чистый **HTML5 + CSS3 + JavaScript (ES2023)**, рендеринг на `<canvas>`
(Canvas 2D API). **Никаких внешних зависимостей и сборщиков не требуется** —
проект представляет собой статический набор файлов и открывается прямо
в браузере или после загрузки на любой веб-хостинг.

Звук реализован через встроенный **Web Audio API** (звуки генерируются
программно, аудиофайлы не требуются). Шрифт `Press Start 2P` подключается
с Google Fonts по CDN (если хостинг без интернета для шрифтов —
игра всё равно работает, просто использует запасной моноширинный шрифт).

Прогресс (лучшее время, количество колец) сохраняется в `localStorage`
браузера.

## Требования к браузеру

Протестировано на актуальных версиях **Google Chrome** и **Safari**
(desktop). Также должно работать в Firefox и Edge, поскольку используются
только стандартные веб-технологии (Canvas 2D, Web Audio API, ES2023,
`localStorage`).

## Управление

| Клавиша | Действие |
|---|---|
| ← / → | Движение шарика |
| ↑ | Прыжок |
| ↓ | Погасить прыжок / отскок от батута |
| R | Рестарт уровня |
| Esc / P | Пауза |
| Enter | Подтверждение в меню |

Размер шарика (надутый/сдутый) меняется **только через насосы на уровне**,
свободного переключения клавишей нет — согласно ТЗ.

## Как развернуть на веб-хостинге

Игра полностью статична, поэтому подходит любой обычный хостинг
статических файлов:

1. Распакуйте архив `bounce-web-demo.zip`.
2. Загрузите **всё содержимое** папки `bounce-web-demo/` (включая
   подпапки `css/` и `js/`) в корень (или подпапку) вашего хостинга —
   например, через FTP, панель управления хостингом, GitHub Pages,
   Netlify, Vercel, Cloudflare Pages и т.п.
3. Откройте `index.html` в браузере по адресу вашего сайта.

Никакой серверной части, базы данных или сборки не требуется —
достаточно, чтобы хостинг отдавал статические файлы (HTML/CSS/JS)
по HTTP/HTTPS.

### Локальная проверка перед загрузкой

Из-за политики браузеров в отношении `file://` рекомендуется открывать
игру через локальный веб-сервер, а не двойным кликом по `index.html`:

```bash
# Python 3
cd bounce-web-demo
python3 -m http.server 8080
# затем открыть http://localhost:8080 в браузере
```

## Известные ограничения демо-версии

- Реализован только один демонстрационный уровень.
- Экран «Настройки» управляет только громкостью — переназначение клавиш
  в демо не реализовано (заложено в архитектуре `InputManager` для
  дальнейшего расширения).
- Значения физики (гравитация, скорость, импульсы батутов) подобраны
  ориентировочно для демонстрации механик и могут потребовать
  дополнительной балансировки в полной версии игры.
